# bravia-x8000h-downgrade

[English](README.md)

我把一台 BRAVIA KD-49X8000H 从 `PKG6.6230`（Android 10）降到了
`PKG6.5086`（Android 9）。这里整理了相关原理、操作步骤，以及几个辅助工具。

做法是把旧固件装进非活动槽，再用 USB fastboot 替换该槽的 `vbmeta`，最后恢复出厂完成
初始化。全程没有拆机，也没有用到 UART 或 eMMC 编程器。

## 实测环境

| 项目 | 配置 |
| --- | --- |
| 电视 | KD-49X8000H，国行固件 |
| 平台 | X8000H 系列 / GN6UR 机芯 / MediaTek MT5893 |
| 降级前 | PKG6.6230.0725CNA，Android 10，版本号 `662301`，槽 B |
| 目标固件 | PKG6.5086，Android 9，版本号 `650861`，安装到槽 A |
| 结果 | Android 9 完成初始化，之后普通重启也能正常进入系统 |

操作只在这台电视和这组固件上验证过。研究涉及 X8000H / GN6UR 平台，但共用机芯或
源码包，不代表其他型号、尺寸和地区版本也适用。

## 动手前

流程会写入固件、解锁引导器、关闭目标槽的 AVB 验证，并清除用户数据，请先备份。
镜像、分区或回滚索引选错，可能导致电视无法启动，也不保证能恢复。DRM 和其他认证功能
没有经过完整测试。使用修改后的元数据时，不要重新锁定引导器。

仓库不附带固件、签名私钥、生成的镜像或第三方可执行文件。
需要准备的文件见[操作步骤](docs/procedure.zh-CN.md#需要什么)；
[其中一节](docs/procedure.zh-CN.md#固件从哪来)给出下载路径的构成，并说明历史版本会从 CDN 清理。
